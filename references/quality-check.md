# 交付前检查

## 内容与范围

- 页数、顺序、语言、受众与交付格式符合要求。
- 标题与正文一致，结论有证据支持，没有把假设写成事实。
- 金额、单位、日期、百分比、合计和图表数据一致。
- 模板中的旧日期、旧项目名、旧数值和占位内容已处理。
- 用户要求保留的表格行列、图表标签、图片、备注与链接没有遗漏。

## 文件与可编辑性

保存后重新打开文件，核对实际展示顺序。确认正文仍是文本、要求编辑的表格与图表仍是原生对象，图表的数据可以更新。对已有文件，比较变更前后的页数及关键对象。

`scripts/inspect_pptx.py` 按 presentation.xml 中的关系读取页面顺序，报告普通文本、备注以及表格、图表、图片对象数量。它支持常见的 Transitional 与 Strict OOXML 命名空间，仅读取 `.pptx`，不解析旧式 `.ppt`、加密文件或图表数据工作簿。抽取的段落顺序是 XML 顺序，不能代表复杂页面的视觉阅读顺序。

对象数量只用于发现可疑变化，不证明所有内容可编辑。截图中的文字、母版继承内容、图表标签或 SmartArt 内容可能不出现在普通文本抽取结果里。检查脚本成功退出也不等同于文件符合全部 OOXML 规范。

需要可执行的检查报告时，运行 [Deck Doctor](deck-doctor.md)，并根据实际约束设置页数和密度阈值。它给出带证据的候选问题，仍需结合内容判断。

## 逐页视觉检查

通过环境中可用且获准使用的渲染器导出图片或 PDF。先看全稿缩略图的一致性，再以能读清文字的尺寸检查每页：

- 文本未超出边界，换行自然，没有缺字或字体替换造成的挤压。
- 图表标签、图例、轴线和表格边界清楚，未被其他对象遮挡。
- 图片没有变形，裁切没有丢失重点。
- 页边距、对齐、留白、页码和颜色保持一致。
- 备注中的来源、演讲补充内容与所在页面相符。

修正问题后重新导出并检查受影响页面。渲染不可用时说明限制，不能用结构检查代替视觉检查结果，也不声称已经在 PowerPoint 中验收。
